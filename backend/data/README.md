# Données de démonstration

Ce dossier contient des échantillons des données ouvertes de la Ville de Montréal, adaptés à une utilisation locale et à une présentation de portfolio.

| Fichier | Contenu du dépôt | Source complète |
| --- | --- | --- |
| `comptage_velo_2022.csv` à `comptage_velo_2025.csv` | 10 000 mesures par année | [Compteurs cyclistes permanents](https://donnees.montreal.ca/fr/dataset/cyclistes) |
| `reseau_cyclable.geojson` | 500 segments du réseau | [Réseau cyclable](https://donnees.montreal.ca/dataset/pistes-cyclables) |
| `fontaines.csv` | Jeu de données complet inclus dans la version portfolio | [Fontaines à boire extérieures](https://donnees.montreal.ca/dataset/fontaines-a-boire-eau-exterieures) |

Pour travailler avec l'ensemble complet, téléchargez les ressources officielles et remplacez les fichiers correspondants en conservant leurs noms et leur schéma.

Ces données demeurent soumises aux conditions d'utilisation de leur fournisseur. La licence MIT du dépôt couvre le code source, pas les jeux de données.
